TRAKWAY TRAIL v3.0.0 - PREMIUM PWA PACKAGE

DEPLOY
Upload every file in this package to the same HTTPS web root. Do not move files into subfolders. Vercel may be used as supplied with vercel.json.

PLAY / INSTALL
Open the HTTPS URL in a modern browser. On Android/Chrome or Edge, use the browser Install App option. On iPhone/iPad Safari, choose Share > Add to Home Screen. After the first complete load, the service worker provides offline play.

QUALITY UPGRADES
- Complete flat-file PWA package with manifest, 192/512/maskable icons and offline cache
- Responsive touch layout for phones and tablets
- Keyboard controls, pause-on-blur, local high scores, sound and safety-aware gameplay
- Production cache versioning and Vercel headers
